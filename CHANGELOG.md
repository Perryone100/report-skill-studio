# Changelog

## 0.4.0 — 2026-08-26

- Added local Markdown project libraries, version recovery, project backup, protected deletion, and privacy controls.
- Added independently configured OpenAI-compatible endpoints and model selection; remote endpoints now require HTTPS.
- Added installable declarative Skills and strengthened template, ZIP, HTML, and PDF isolation.
- Added process-local write-request tokens plus Host and Origin validation for the local API.
- Added CodeQL, Dependabot, pinned GitHub Actions, community templates, and privacy/security documentation.
- Unified workspace package versions and separated server dependency composition, HTTP security, and database schema modules.

The bundled `default-weekly-meeting` Skill keeps its own independent `0.3.1` content/schema version.
